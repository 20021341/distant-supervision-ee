## Overview

Vietnamese Silver Event Extraction Dataset is a comprehensive repository containing event extraction data for the Vietnamese language, extended with additional silver data. This repository focuses on enriching the dataset using distant supervision and silver corpus generation techniques, employing the model described in [Joint Information Extraction with Token-Pair Labeling (FourIE)](https://arxiv.org/abs/2103.09330) for predicting data.

## Dataset Description

This dataset features event extraction data augmented with raw texts crawled from BaoMoi and applies silver data generation techniques. The goal is to provide enriched training and evaluation data for Vietnamese Event Extraction tasks.

It contains:
- Processed baseline data matching the code requirements.
- Multiple attempts/versions of dataset enrichment.
- Raw crawled texts from BaoMoi.
- Data predictions generated by the FourIE model.

### JSON Structure

The training and testing data files (such as `train.json` and `test.json` in the `final_data/processed/` directory) are formatted in JSONL (JSON Lines). Each line contains a JSON object representing a single sentence, structured as follows:

```json
{
    "doc_id": "train-00000",
    "sent_id": "train-00000",
    "tokens": ["Ngày", "26/11", ",", "Bộ", "Tài chính", "khai trương", "giao diện", "mới", "Cổng", "thông tin", "điện tử", "Bộ", "Tài chính", "và", "Kho bạc", "Nhà nước", "."],
    "sentence": "Ngày 26/11 , Bộ Tài chính khai trương giao diện mới Cổng thông tin điện tử Bộ Tài chính và Kho bạc Nhà nước .",
    "pieces": ["▁Ngày", "▁26", "/11", ",", "▁Bộ", "▁Tài", "▁chính", "▁khai", "▁trương", "▁giao", "▁diện", "▁mới", "▁Cổ", "ng", "▁thông", "▁tin", "▁điện", "▁tử", "▁Bộ", "▁Tài", "▁chính", "▁và", "▁Kho", "▁bạc", "▁Nhà", "▁nước", "."],
    "token_lens": [1, 2, 1, 1, 2, 2, 2, 1, 2, 2, 2, 1, 2, 1, 2, 2, 1],
    "entity_mentions": [
        {
            "id": "train-00000-T2",
            "text": "Bộ Tài chính",
            "entity_type": "ORG",
            "start": 3,
            "end": 5,
            "start_char": 13,
            "end_char": 25,
            "mention_type": "UNK"
        }
    ],
    "event_mentions": [
        {
            "id": "train-00000-T3",
            "event_type": "Start-org",
            "trigger": {
                "text": "khai trương",
                "start": 5,
                "end": 6,
                "start_char": 26,
                "end_char": 37
            },
            "arguments": [
                {"entity_id": "train-00000-T2", "text": "Bộ Tài chính", "role": "Agent"}
            ]
        }
    ],
    "relation_mentions": []
}
```

#### Field Descriptions

- **doc_id**: Unique document identifier
- **sent_id**: Unique sentence identifier
- **tokens**: Array of word tokens from the sentence
- **sentence**: Complete text of the sentence
- **pieces**: Subword tokens (commonly used by transformer models)
- **token_lens**: Length of each token based on subwords
- **entity_mentions**: Annotated entities in the sentence, including their entity type and character positions
- **event_mentions**: Annotated events in the sentence, including the event trigger and its corresponding arguments with roles
- **relation_mentions**: Annotated relations (if any) between entities in the sentence


## Getting Started

1. Clone the repository:
```bash
git clone <your-repository-url>
cd <repository-directory>
```

2. Explore the data directories, particularly `final_data/` for the enriched datasets and `result/` for the model predictions.

## Usage

### Scripts

The repository includes several Python scripts for different stages of the processing pipeline:

- **Silver Corpus Generation**: Use `generate_silver_corpus.py` to generate the silver corpus based on the provided data.
- **Schema Augmentation**: Run `schema_augment.py` to perform schema augmentation tasks.
- **Trend Detection**: Execute `trend_detection.py` to run the trend detection algorithm over the extracted events.
